# Integrated Agile Workflow

Milestone 1: Create Event → Venue Capacity/Conflict → Resource Availability/Allocation → Lifecycle → Reports.

Milestone 2: Participant Registration → Validation/Duplicate Check → Ticket → QR → Vendor Registration → Vendor Assignment → Check-in → Attendance → Notifications → Reports.

The same Event record connects both milestones, so venue/resource planning is completed before participant registration and the same event is used for vendors, tickets, attendance and reports.
